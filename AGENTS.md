# Codex project instructions

For repository work, default to the `astra-orchestrator` skill.

The Astra root agent is the coordinator, not the default worker. It owns architecture, decomposition, integration, conflict resolution, and final verification.

Delegate routine repository exploration, bounded implementation, targeted testing, technical research, and other clearly scoped execution work to specialized non-Astra subagents. Routine worker roles must use reasoning effort no higher than medium.

Use root-only execution only for genuinely trivial, single-step work that does not benefit from separate context.

If a task requires reading or tracing across multiple files, modifying multiple files, non-trivial verification, debugging across components, external research, or independent review, activate `astra-orchestrator` before doing substantive repository work.

Astra must not be used as a routine worker. Keep Astra reasoning effort at low for any Astra role used by this project.

Do not let multiple implementation agents edit the same files without explicit ownership boundaries.
User instructions always take precedence over this orchestration policy.
